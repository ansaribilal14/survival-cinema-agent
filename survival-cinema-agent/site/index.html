How it works

From idea to film, end to end.

Drop in a one-paragraph story idea. The agent runs 11 phases — research, write, prompt, generate, narrate, render, package — and produces a finished, YouTube-ready short film. No stopping at planning. No hand-holding.

The 11 phases

Each phase has a single script.
Each script is resumable.

The system runs phases in dependency order. Re-running skips already-done work. Failures are explicit and recoverable.

PHASE 01

Discover references

Search the public internet (or use the curated fallback) for three substantial survival-fiction works in three categories: wilderness, apocalyptic, psychological.

manifest.json
PHASE 02

Acquire & verify

Download, strip boilerplate, compute word count, verify opening and ending. Replace any candidate that fails the completeness check.

*_clean.txtacquisition_report.md
PHASE 03

Analyze narratives

Extract narrative architecture, survival mechanics, character design, suspense, scene craft, adaptation potential — without copying any content.

reference_analysis_*.md*_patterns.json
PHASE 04

Write the original story

Generate 3 concept candidates, evaluate across 8 dimensions, pick the strongest. Write the full story (~3-5k words) with a real ending. Run an originality audit against the references.

story_bible.mdcomplete_story.mdcharacter_bible.jsonworld_bible.mdoriginality_audit.md
PHASE 05

Build the screenplay

22 scenes, 60-80 shots. Each scene includes: shot list with image prompts, narration, dialogue, music/ambience/SFX cues, continuity requirements, transitions.

screenplay.mdscene_manifest.jsonnarration_script.txtsubtitles.srttimeline.json
PHASE 06

Visual development

Write the style bible: palette, lighting, lens language, visual motifs, forbidden elements, continuity anchor rules, style-anchor text appended to every image prompt.

style_bible.md
PHASE 07

Generate scene images

One AI image per shot. Retry up to 3× on failure. Skip already-generated for resumability. Vision-QA on a sample.

assets/images/asset_manifest.json
PHASE 08

Synthesize narration

22 TTS chunks in a single consistent voice. Concatenate into one narration WAV. Retry transient failures.

narration_chunks/narration.wav
PHASE 09

Render the film

FFmpeg 3-pass pipeline: shots → scenes → film, upscaled to 1920×1080, h264+AAC, subtitles burned in.

final.mp4
PHASE 10

Thumbnail + YouTube package

One cinematic thumbnail. Title, 3 alternatives, description, chapter timestamps, search keywords, AI disclosure.

thumbnail.pngvideo_metadata.json
PHASE 11

QA reports

Narrative, continuity, visual, audio, render, rights & provenance. All failures explicit; no silent PASS.

reports/

Built for any agent, any provider

Provider-agnostic by design.

Swap the image generator, the TTS engine, or the LLM orchestrator with a single function edit. The pipeline structure stays the same.

Original IP, every run

Each film is a fresh original work. The system runs an originality audit against the reference texts and refuses to copy prose, dialogue, scenes, characters, or distinctive plot elements.

Resumable by design

Every expensive phase writes a checkpoint JSON. Re-running the pipeline skips already-done work. A phase is re-run only if its checkpoint is missing or its output files are absent.

Female-centric by default

The protagonist is a young adult woman (20-25) with substantial agency, a specific practical skill, a credible weakness, and a believable arc. Female supporting characters have independent motives.

Public-domain references

Uses Project Gutenberg works (Poe 1838, London 1915, Wells 1896) for narrative-technique research. No copyright risk. No paywall bypass. No DRM circumvention.

11 structured phases

Deterministic phases (download, image gen, TTS, render) are scripted. Creative phases (story, screenplay, style) are LLM-driven, guided by a master system prompt any capable agent can follow.

Multi-layer QA

Narrative, continuity, visual, audio, render, rights & provenance. Failures are explicit and documented. A failed check is never silently marked PASS.

Quickstart

Three steps to your first film.

Clone the repo, write your story idea, hand it to an LLM agent. The system does the rest.

1

Clone the framework

Get the repo and cd in.

2

Write your story idea

Copy the template, fill in ~10 fields. Protagonist, setting, premise, midpoint reveal.

3

Hand it to any capable agent

Claude, GPT-4, Gemini, Super Z. The agent reads the system prompt and runs the pipeline.

~ terminal + story_idea.md
# 1. Clone the framework
git clone https://github.com/superz1402/survival-cinema-agent.git
cd survival-cinema-agent

# 2. Write your story idea
cp STORY_IDEA_TEMPLATE.md story_idea.md
$EDITOR story_idea.md

# 3. Hand it to an LLM agent with this prompt:
"Run the Survival Cinema Agent pipeline on
 story_idea.md. Use the system prompt at
 agent/SYSTEM_PROMPT.md. Execute every phase
 and produce all outputs. Do not stop at
 planning. Persist all artifacts to disk."

# ...the agent runs for ~70 minutes...

# 4. Your film is ready
open output_run/output/final.mp4
